# iPod USB-C Conversion Kit v2: install guide and bezel files

Replace the 30-pin dock connector on an iPod Classic (6th, 6.5th and 7th gen), iPod Video (5th and 5.5th gen) or iPod mini with a USB-C port that charges and syncs.

- **[Install guide (PDF)](guide/v2-install-guide.pdf)**: an illustrated two-page guide with test points for each model.
- **[bezel/](bezel/)**: 3D-printable USB-C port bezels (STL):
  - `ipod-classic-video-usbc-bezel.stl`: iPod Classic / Video
  - `ipod-mini-usbc-bezel.stl`: iPod mini

The kit is sold on eBay. Questions: see [ipodmod.com](https://ipodmod.com).

Opening and modifying your iPod is at your own risk.
